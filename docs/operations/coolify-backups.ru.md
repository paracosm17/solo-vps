# Экспорт зашифрованной копии Coolify

Запускайте **на рабочей машине в Bash/WSL**, из каталога исходников Solo VPS. Одна команда создаёт свежую копию управляющей части Coolify, скачивает её по SSH и сохраняет проверенный `.tar.gz.age` локально. S3 и опциональный профиль restic не нужны.

## Состав и границы

В архив входят база Coolify (PostgreSQL dump в custom-формате), конфигурация исходников, серверные SSH-ключи, конфигурация/сертификаты proxy, конфиг/inventory оператора и метаданные контейнеров платформы. Внутренний manifest содержит ревизию исходников, время создания и SHA256 каждого файла.

**Базы и тома приложений не входят.** Для них сохраняйте отдельные [копии PostgreSQL](postgresql-backups.md) и [внешние копии данных](offsite-backups.md). Также исключены образы Docker, access logs, старые checkpoints и SSH/age identities рабочей машины. Свежий экспорт заменяет необходимость собирать прежние checkpoints обновлений, но никогда их не удаляет.

Снимок базы и файлов конфигурации не атомарен. Дождитесь завершения деплоев и приостановите обновления/правки настроек на время экспорта. Проверка структуры dump и расшифрованных файлов доказывает целостность архива, а не полное восстановление. Автоматической команды restore/downgrade для этого архива нет; см. [границы восстановления](../upgrades.md#rollback-recovery).

## Подготовить один раз

Используйте существующий SSH-ключ администратора и проверенный ключ сервера в `known_hosts` рабочей машины. Запросы пароля отключены. У администратора должен работать sudo без запроса пароля, как настроено Solo VPS. Стандартные пути на сервере: `/home/<admin>/solo-vps` и `/home/<admin>/.local/share/solo-vps`; в последнем нужны `config/config.yml` и `config/hosts.yml`.

Платформа должна быть здорова. Сборщик передаётся временным Python-кодом по SSH; устанавливать исходники этой функции на VPS не нужно.

Храните age identity на рабочей машине в `~/.config/solo-vps/age-key.txt` либо укажите `AGE_KEY_FILE`. Установите криптографические инструменты проекта с проверкой контрольных сумм:

```bash
make secrets-tools
```

## Экспортировать

Если на рабочей машине уже есть single-host inventory:

```bash
make coolify-backup-export
```

Если контроллер Solo VPS работает на самом сервере, укажите адрес подключения вместо ведения второго inventory на рабочей машине:

```bash
make coolify-backup-export BACKUP_VPS_HOST=203.0.113.10 BACKUP_VPS_USER=ops
```

Команда напечатает итоговый локальный путь: по умолчанию каталог `backups/` внутри data root рабочей машины из `make paths`. **Файл уже скачан.** Отдельный SCP не нужен. Приватный age-ключ не передаётся на VPS; открытые архивы не записываются на диск рабочей машины. Временные файлы сбора на VPS приватны и удаляются после этого запуска, в том числе при ошибке; прежние checkpoints/бэкапы сохраняются.

Чтобы сохранить сразу в каталог Windows из WSL:

```bash
make coolify-backup-export \
  BACKUP_VPS_HOST=203.0.113.10 BACKUP_VPS_USER=ops \
  AGE_KEY_FILE=/mnt/c/Users/YOUR_USER/.config/solo-vps/age-key.txt \
  COOLIFY_BACKUP_OUTPUT=/mnt/c/Users/YOUR_USER/solo-vps-backups/pre-update.tar.gz.age
```

Нужен новый путь с расширением `.age` вне каталога исходников; существующие файлы не перезаписываются. Для нестандартных каталогов задайте `COOLIFY_BACKUP_REMOTE_DATA_DIR`, `COOLIFY_BACKUP_REMOTE_SOURCE`, а при необходимости — `BACKUP_SSH_IDENTITY_FILE`. Чтение inventory поддерживает ровно один прямой host с адресом/пользователем, опционально портом/путём приватного ключа, без наследуемых или специальных настроек подключения Ansible.

Штатные ошибки очищают временные файлы этого запуска. Убитый процесс или потеря соединения могут оставить приватный staging либо локальный `.partial`; повторите с новым именем файла и проверьте принадлежность остатков перед удалением. Передача не возобновляется.

Перед публикацией итогового имени экспортер проверяет коды завершения сбора/шифрования, расшифровывает поток локально для сравнения полного SHA256, затем вторым проходом проверяет каждый файл по manifest. Ошибка не оставляет файл, похожий на успешный бэкап. Отдельно сохраняйте age identity: при его потере архив прочитать невозможно.
