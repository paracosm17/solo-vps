# Выбор лицензии — Apache-2.0

Solo VPS использует **Apache License 2.0**. Владелец проекта выбрал её **2026-08-11**.

- SPDX-идентификатор: `Apache-2.0`
- канонический текст: файл `LICENSE` в корне репозитория
- вклад в проект должен быть совместим с распространением по Apache-2.0

Эта лицензия остаётся permissive, при этом явно определяет условия patent grant/termination. Не добавляйте собственную, двойную или отдельную лицензию для подсистемы без отдельного решения по проекту.

Не создавайте пустой `NOTICE` как формальный boilerplate; добавляйте notice-материалы только при реальной необходимости в attribution или юридическом требовании.

Эта страница фиксирует инженерное решение. Авторитетным источником остаётся текст лицензии, а это резюме **не является юридической консультацией**.
